# 2-2일차 문제 풀이

## 프로세스

## **해설**
- 큐 맨 앞에 있는 문서를 꺼내, 그 문서보다 우선순위가 높은 문서가 큐에 남아있으면 맨 뒤로 다시 넣음.
- 자신보다 높은 우선순위의 문서가 없으면 인쇄함.
- 과정 반복 중, location 위치의 문서가 인쇄되는 순서를 리턴.

**코드**

```python
def solution(priorities, location):
    answer = 0
    while len(priorities) > 0:
        max_priority = max(priorities)
        if priorities[0] == max_priority:
            answer += 1
            priorities.pop(0)
            if location == 0:
                break
            else:
                location -= 1
        else:
            priorities.append(priorities.pop(0))
            if location == 0:
                location = len(priorities) - 1
            else:
                location -= 1
    return answer
```

1. 가장 높은 우선순위 max_priority를 만듦.
2. priorities[0]이 max_priority와 같다면 answer 1 증가 후 큐에서 꺼냄.
3. 이때 꺼낸 문서가 주어진 location이라면, 반복문을 break하고, 아니라면 location 1 감소
4. priorities[0]이 max_priority와 같지 않다면 맨 뒤로 옮김.
5. 이떄, location이 맨 뒤로 밀려났으면 location을 len(priorities) -1로 갱신하고, 아니라면 1 감소시킴
