# 2-1일차 문제 풀이

## 기능개발

## **해설**
- 작업의 개수는 100개 이하임.
- 배포는 하루에 한 번 할 수 있음. (진도율 95%인 작업의 개발 속도가 하루에 4%라면, 배포는 2일 뒤에 이루어짐)
- 뒤에 있는 기능이 앞 기능보다 일찍 완성된 경우, 앞 기능이 배포될 때 같이 배포됨.

**코드**

```python
def solution(progresses, speeds):
    answer = []
    days = []
    cnt = 1
    for i in range(len(progresses)):
        if (100 - progresses[i]) % speeds[i] == 0:
            days.append((100 - progresses[i]) // speeds[i])
        else:
            days.append((100 - progresses[i]) // speeds[i] + 1)
    for i in range(1, len(days)):
        if days[i] > days[i-1]:
            answer.append(cnt)
            cnt = 1
        else :
            cnt += 1
            days[i] = days[i-1]
    answer.append(cnt)
   
    return answer
```

1. progresses 들이 순서대로 며칠 걸리는 지 days 배열에 넣음.
2. 다음 날 작업이 전 날 작업보다 오래 걸린다면, 정답 배열에 추가 후 cnt 초기화.
3. 다음 날 작업이 전 날 작업이랑 동시에 끝나거나, 일찍 끝난다면, cnt 1 증가, days[i] 값을 큰 값으로 변경.
4. 반복분이 끝난 뒤, cnt값을 answer 배열에 넣고 리턴함.
